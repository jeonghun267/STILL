# STILL

Unity 6 기반의 VR 수중 생태 관찰 프로젝트입니다. 해안가 해양 관측소 로비에서 출발해 엘리베이터로 수중 돔에 내려가고, 미스터리 상자에서 만난 해양생물을 한국어 설명과 음성 해설로 관찰하며 개인별 관찰 일지에 기록합니다.

> 지구 표면의 71%는 바다지만, 그 바다의 80% 이상은 아직 아무도 본 적이 없습니다. STILL 은 생물을 잡아 모으는 대신, 아직 모르는 바다를 한 칸씩 기록하는 관찰 체험입니다.

## 개발 환경

- Unity 6.3 LTS (`6000.3.16f1`)
- Android / Meta Quest
- XR Interaction Toolkit 및 OpenXR
- Gemini 기반 생물 설명과 Android 기본 TTS

### `land-lobby-intro` — 육지에서 시작

- 해 질 녘 해양 관측소 로비: 바다가 보이는 통유리창과 테라스, 1930년 바시스피어 전시, 개찰구, STILL 간판, "지구의 71% 는 바다 · 그중 80% 는 아무도 못 봤다" 데이터 월.
- `LobbySequence`: 자막 나레이션 → "입장하기" → 개찰구를 지나 엘리베이터까지 짧은 직선 자동 걷기 → 내려가는 동안 수심 표시 → 검은 화면 뒤에서 수중 돔으로.
- 멀미 완화: 일정한 속도의 직선 걷기, 움직이는 동안 가장자리 비네트, 장소가 바뀔 때마다 페이드.
- "수집" 대신 "관찰" 용어(관찰 일지 · 다음 탐사 · 미관찰), 외부 에셋 출처는 `Assets/ThirdParty/CREDITS.md`.
- 적용 메뉴: `DomeAquarium/9. 육지 로비 빌드`.

### `hands-on-observation` — 직접 겨눠서 관찰

- 관찰기(`ObservationAim`): 오른손으로 헤엄치는 물고기를 겨누고 링이 다 찰 때까지 지켜보면 기록된다. 수중 돔에서는 물고기 떼를, 로비에서는 연습 수조를 겨눈다.
- 로비 준비 단계(`LobbyTutorial`): 텔레포트 · 스냅 회전으로 이동 → 장비대에서 관찰기 집기 → 연습 수조에서 첫 기록 → 개찰구가 열리면 엘리베이터 타기.
- 로비를 12 × 15m, 천장 4.5m 로 넓히고, 정보 카드 · 관찰 일지를 10~15세에 맞게 다시 짰다.
- 적용 메뉴: `DomeAquarium/17. 관찰기 적용 (상자 대신 직접 관찰)`.

### `lobby-depth-wall-live-sea` — 수심 벽과 창밖 바다

- 수심 벽(`DepthWallPreview`): 24m · 200m · 1,000m 띠를 만지면 5초 동안 그 깊이의 빛 · 안개 · 소리가 로비에 퍼진다.
- 버튼을 VR Template 에셋 기반으로 다시 만들고(`DomeAquariumUiKit.PokeButton`), 손목 메뉴에 "N / 98종 기록" 진행 막대를 넣었다.
- 창밖 진짜 바다(`SeaSurface`)와 돌고래 · 만타가오리 · 가다랑어가 물 위로 뛰어오르는 쇼(`SeaJumpShow`).

### `layered-dive-ending` — 1,000m 까지 내려가고 밤에 돌아온다

- 층별 하강(`DiveMission`, `DiveDirector`): 층마다 할 일 → 관찰 → 완료 → 엘리베이터 → 다음 층. 엘리베이터 계기판에서 24m / 200m / 1,000m 를 고르고, 위층을 마쳐야 아래층이 열린다.
- 200m: 바위 바닥, 마린 스노우, 대형 종 8가지가 60~90초마다 지나간다.
- 1,000m "가만히": 관찰 조명(A/X 버튼)을 끄고 5초 동안 움직이지 않으면 정체 모를 생물이 다가온다(`StillnessDetector`, `UnknownCreature`).
- 엔딩: 1,000m → 0m 자동 상승, 밤 로비, 데이터 월에 새 줄, 마지막 나레이션, 크레딧, "처음부터 다시".
- 적용 메뉴: `DomeAquarium/18. 층별 하강 적용 (24m → 200m → 1,000m)`.

### `end-credits-placement` — 크레딧 자리 고정

- 크레딧을 보던 방향 기준(왼쪽 40°)이 아니라 데이터 월 새 줄의 왼쪽 끝 기준으로 세운다. 창 쪽을 보고 있으면 판이 새 줄 위에 얹히던 문제를 고쳤다.
- 판 바탕을 불투명하게 해 뒤의 글자와 빛줄이 비치지 않는다.

### `lobby-stick-locomotion` — 막대로 걷고 부드럽게 돈다

- 왼쪽 막대로 걷기(1.5 m/s, 보는 방향 기준), 오른쪽 막대 좌우로 부드러운 회전(60°/s), 오른쪽 막대를 앞으로 밀었다 놓으면 텔레포트.
- 로비 벽에는 충돌체가 없어서, 걸을 수 있는 곳(개찰구가 열리기 전에는 개찰구 앞, 열린 뒤에는 홀 전체와 엘리베이터 칸 통로) 밖으로 나가면 되돌린다.
- 로비를 다시 세우지 않고 지금 씬에만 적용: `DomeAquarium/디버그/로비 이동 방식 다시 적용 (걷기·부드러운 회전)`.

### `reef-school-rotation` — 24m 무리 교체

- 동시에 헤엄치는 150마리(Quest 예산)는 그대로 두고, 100~160초마다 무리 하나가 돔 물 벽 너머로 나가고 아직 안 나온 종이 들어온다(`BoidManager`).
- 볼거리와 해마류 5종은 늘 남고, 나머지 산호초 64종이 차례로 나온다. 그동안 안 쓰던 붉은바다거북 · 얼룩말해마와 작은 산호초 어종 49종이 이제 나온다.
- 관찰 일지는 실제로 만날 수 있는 95종만 센다(강돌고래 3종 제외).
- 적용 메뉴: `DomeAquarium/18. 층별 하강 적용 (24m → 200m → 1,000m)`.

## 변경 기록

새 작업을 반영할 때마다 해당 날짜 제목 아래에 변경 사항을 추가합니다.

### 2026-10-21

- Meta Quest 에서 막대로 걸을 수 없고 회전이 뚝뚝 끊기던 로비 이동을 바꿨습니다.
  - 왼쪽 막대로 걷고(1.5 m/s, 보는 방향 기준), 오른쪽 막대 좌우로 부드럽게 돕니다(60°/s). 오른쪽 막대를 앞으로 밀었다 놓으면 지금처럼 텔레포트합니다.
  - 씬 빌더가 리그에서 걷어 낸 연속 이동·연속 회전 제공자를 로비 빌더가 다시 붙이고, 스냅 회전은 끕니다. 컨트롤러의 `ControllerInputActionManager` 를 왼손 걷기 · 오른손 부드러운 회전으로 나눕니다.
  - 로비 벽에는 충돌체가 없어, 머리가 걸을 수 있는 곳(홀 안쪽, 개찰구가 열린 뒤에는 엘리베이터 칸 통로까지) 밖으로 나가면 리그를 되돌립니다 (`LobbyTutorial`).
  - 로비를 다시 세우지 않고 지금 씬에만 적용하려면 `DomeAquarium/디버그/로비 이동 방식 다시 적용 (걷기·부드러운 회전)` 을 실행하고 씬을 저장합니다.
- 브랜치를 기능별로 나누고(`land-lobby-intro` 는 첫 기능 커밋 `62e222b` 로 되돌림), 위에 브랜치 안내를 추가했습니다. 브랜치 이름 앞의 `feat/` · `fix/` · `docs/` 는 뺐습니다.
- 24m 산호초의 물고기 무리가 몇 분마다 바뀝니다 (`BoidManager` 무리 교체, `DiveMission.rotation`, `DomeAquarium/18. 층별 하강 적용`).
  - 동시에 헤엄치는 150마리(Quest 드로우콜 예산)는 그대로 두고, 100~160초마다 교체 대상 무리 하나가 돔의 물 벽 너머로 헤엄쳐 나가고, 이번 탐사에 아직 안 나온 종이 같은 자리(슬롯)를 받아 벽 너머에서 헤엄쳐 들어옵니다.
  - 볼거리(상어 · 가오리 · 거북 · 돌고래 · 흰동가리 등)와 해마류 5종은 늘 남고, 나머지 산호초 64종이 교체 후보입니다. 처음에는 38종 150마리가 헤엄칩니다.
  - 그동안 안 쓰던 붉은바다거북과 얼룩말해마는 늘 나오고, 나머지 작은 산호초 어종 49종(엔젤피시 · 탱 · 나비고기 · 자리돔 · 망둑어 · 흰동가리 · 도티백 · 바슬렛 · 카디널 · 그루퍼)은 교체로 나옵니다. 강에 사는 돌고래 3종은 그대로 뺍니다.
  - 관찰 일지는 실제로 만날 수 있는 종만 셉니다 (98종 → 95종, 강돌고래 제외).
  - 헤드셋 없이 확인: 교체 간격을 2~3초로 줄여 4배속으로 약 400초 돌렸을 때 마릿수는 내내 150 이었고, 나온 종은 38 → 50종으로 늘었습니다.

### 2026-10-17

- 1막 관찰 프로토타입: 미스터리 상자 대신 헤엄치는 생물을 오른손으로 겨누고 지켜봐서 기록하는 관찰기(`ObservationAim`)를 추가했습니다 (`DomeAquarium/17. 관찰기 적용`).
  - 조준 원뿔(5°) 안의 개체를 `BoidManager` 조회 API로 찾고, 같은 종을 체장에 따라 1.5~3초 지켜보면 관찰 일지에 기록합니다. 놓치면 진행이 천천히 줄어듭니다.
  - 기록하면 셔터음·진동과 함께 정보 카드와 음성 해설이 뜨고, 생물은 그대로 헤엄쳐 갑니다. 이미 기록한 종은 이름과 "기록됨"만 보여 줍니다.
  - 겨눈 생물에 진행 링과 이름 줄, 손 위에 안내·이번 탐사 기록 수를 띄웁니다. 관찰 일지를 연 동안은 겨누지 않습니다.
  - 손목 메뉴의 "다시 뽑기"를 숨겼습니다. `디버그/관찰기 끄고 상자 되돌리기`로 예전 흐름과 번갈아 테스트할 수 있습니다.
  - 헤드셋 없이 에디터에서는 게임뷰 마우스로 겨누고, `디버그/플레이 중 - 관찰기 자동 겨누기`로 기록 흐름을 끝까지 돌려 볼 수 있습니다.
- 관찰기 표시를 Meta·Microsoft·Apple·Android XR 가이드라인 수치에 맞췄습니다.
  - 링은 시야각 3°(큰 생물은 최대 1.6배)로 대상 깊이에 그리고, 0.2초 겨눈 뒤에야 띄웁니다.
  - 기록 진동은 175ms 동안 세지는 두 번, 셔터음은 생물 위치의 3D 소리로 냅니다.
  - 카드는 눈높이 5~30° 아래에만 놓고, 패널 바탕의 가장 어두운 채널도 15/255 이상으로 올렸습니다.
- 생물 정보 카드를 레이아웃 그룹으로 다시 짰습니다 (`DomeAquarium/12. 정보 패널 스타일 및 관람 배치 적용`).

- 산호와 해초의 시간대별 발광 및 주변 조명 효과를 보강했습니다.
- `Aquatic Downtime` BGM을 추가하고 시작 페이드인, 도감·뽑기·TTS 상황별 자동 음량 조절을 적용했습니다.
- 긴 MP3를 Streaming/Vorbis 방식으로 설정하고 백그라운드 로딩을 활성화했습니다.
- Unity 비정상 종료로 생성되는 `Assets/_Recovery` 백업은 Git 추적 대상에서 제외했습니다.
