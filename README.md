# STILL

Unity 6 기반의 VR 수중 생태 관찰 프로젝트입니다. 해안가 해양 관측소 로비에서 출발해 엘리베이터로 수중 돔에 내려가고, 미스터리 상자에서 만난 해양생물을 한국어 설명과 음성 해설로 관찰하며 개인별 관찰 일지에 기록합니다.

> 지구 표면의 71%는 바다지만, 그 바다의 80% 이상은 아직 아무도 본 적이 없습니다. STILL 은 생물을 잡아 모으는 대신, 아직 모르는 바다를 한 칸씩 기록하는 관찰 체험입니다.

## 개발 환경

- Unity 6.3 LTS (`6000.3.16f1`)
- Android / Meta Quest
- XR Interaction Toolkit 및 OpenXR
- Gemini 기반 생물 설명과 Android 기본 TTS

## 변경 기록

새 작업을 반영할 때마다 해당 날짜 제목 아래에 변경 사항을 추가합니다.

  - 기록하면 셔터음·진동과 함께 정보 카드와 음성 해설이 뜨고, 생물은 그대로 헤엄쳐 갑니다. 이미 기록한 종은 이름과 "기록됨"만 보여 줍니다.

  - 창유리 위(2.6m)에 "창밖 바다를 지켜보세요" 안내판을 붙였습니다. 헤드셋 없이 확인: `디버그/플레이 중 - 로비: 창밖 점프 보기 (차례로)`.

- 체험이 수중이 아니라 육지에서 시작하도록 해 질 녘 해양 관측소 로비를 추가했습니다 (`DomeAquarium/9. 육지 로비 빌드`).
  - 통유리창 너머 바다, 1930년 바시스피어 전시, 개찰구, `STILL` 간판과 71%·80% 데이터 월로 구성했습니다.
  - 나레이션 자막 뒤 "입장하기"를 누르면 개찰구를 지나 엘리베이터로 걸어 들어가고, 수심 계기판과 함께 수중 돔으로 내려갑니다.
