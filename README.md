# STILL

Unity 6 기반의 VR 수중 생태 관찰 프로젝트입니다. 해안가 해양 관측소 로비에서 출발해 엘리베이터로 수중 돔에 내려가고, 미스터리 상자에서 만난 해양생물을 한국어 설명과 음성 해설로 관찰하며 개인별 관찰 일지에 기록합니다.

> 지구 표면의 71%는 바다지만, 그 바다의 80% 이상은 아직 아무도 본 적이 없습니다. STILL 은 생물을 잡아 모으는 대신, 아직 모르는 바다를 한 칸씩 기록하는 관찰 체험입니다.

## 개발 환경

- Unity 6.3 LTS (`6000.3.16f1`)
- Android / Meta Quest
- XR Interaction Toolkit 및 OpenXR
- Gemini 기반 생물 설명과 Android 기본 TTS

## 변경 기록

새 작업을 반영할 때마다 해당 날짜 제목 아래에 변경 사항을 추가합니다.

### 2026-10-02

- 체험이 수중이 아니라 육지에서 시작하도록 해 질 녘 해양 관측소 로비를 추가했습니다 (`DomeAquarium/9. 육지 로비 빌드`).
  - 통유리창 너머 바다, 1930년 바시스피어 전시, 개찰구, `STILL` 간판과 71%·80% 데이터 월로 구성했습니다.
  - 나레이션 자막 뒤 "입장하기"를 누르면 개찰구를 지나 엘리베이터로 걸어 들어가고, 수심 계기판과 함께 수중 돔으로 내려갑니다.
- 멀미를 줄이도록 자동 걷기는 일직선·등속으로 짧게 두고, 걷는 동안 시야 가장자리를 어둡게 하며, 장소 전환은 검은 화면 뒤에서 처리했습니다.
- "채집·뽑기·도감" 대신 "관찰 기록·탐사·관찰 일지" 용어를 쓰고, 희귀도를 관측 빈도(흔함~극히 드묾)로 바꿨습니다.
- 외부 에셋 출처와 라이선스를 `Assets/ThirdParty/CREDITS.md`에 정리했습니다. CC-BY 에셋은 크레딧 화면에 표기가 필요합니다.
- 머티리얼 URP 변환이 반투명(유리)과 발광(네온) 재질도 처리하도록 보강했습니다.

### 2026-09-01

- 평면 모래 바닥에 실제 지형 없이 적용되던 산호 군락의 계단 높이를 제거했습니다.
- 산호·바위·해초·조개의 프리팹 피벗 대신 실제 렌더러 최하단을 기준으로 바닥에 자동 접지하도록 개선했습니다.
- 접지된 오브젝트를 모래에 1.5cm 묻어 작은 틈과 그림자 부유 현상을 방지했습니다.

### 2026-08-31

- 물고기 데이터에 한글 이름, 영문·학명 표기, 안정적인 종 식별자와 한국어 설명 폴백을 추가했습니다.
- Gemini가 생물 종을 특정해 설명하도록 프롬프트와 응답 처리 과정을 보강했습니다.
- 물고기 이름과 설명을 읽어 주는 Android 한국어 TTS를 추가했습니다.
- 정보 카드를 청록색 수중 태블릿 스타일로 개선하고 희귀도 명칭과 음성 안내 UI를 정리했습니다.
- 로컬 탐험가 3명의 발견 기록을 분리해 저장하는 해양생물 도감을 추가했습니다.
- 발견 카드, 희귀도 필터, 페이지 이동, 360도 3D 미리보기와 음성 해설을 구현했습니다.
- 도감 미리보기와 뽑기 전시 모델이 화면 밖에 남지 않도록 생성·정리 수명주기를 보강했습니다.
- 참다랑어 같은 대형 생물이 설명 UI와 겹치지 않도록 전시 크기와 위치를 자동 보정했습니다.
- 생물의 전체 수영 속도를 낮추고 회전 및 전시 동작을 부드럽게 조정했습니다.
- 상자 등장과 시작 버튼 연출의 사각 파티클을 전용 거품 효과로 교체했습니다.
- 상자와 전시 무대를 사용자에게서 조금 멀리, 화면 중앙에 가깝게 재배치했습니다.
- 수조 내부 바닥 재질과 벽 구조를 정리하고 천장을 닫아 외부 하늘이 노출되지 않게 했습니다.
- 산호와 해초의 시간대별 발광 및 주변 조명 효과를 보강했습니다.
- `Aquatic Downtime` BGM을 추가하고 시작 페이드인, 도감·뽑기·TTS 상황별 자동 음량 조절을 적용했습니다.
- 긴 MP3를 Streaming/Vorbis 방식으로 설정하고 백그라운드 로딩을 활성화했습니다.
- Unity 비정상 종료로 생성되는 `Assets/_Recovery` 백업은 Git 추적 대상에서 제외했습니다.
